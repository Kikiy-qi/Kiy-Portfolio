# Kiy Portfolio

Portofolio web responsif yang memuat kurasi proyek, showcase media visual, serta integrasi *chatbot* interaktif berbasis Groq API.

## Fitur

* **AI Chatbot**: Asisten interaktif bertenaga Groq LLM untuk menjawab pertanyaan seputar portofolio dan proyek secara instan.
* **Media Showcase**: Galeri kurasi untuk dokumentasi karya visual, fotografi, dan proyek teknis.
* **Zero Overhead**: Dibangun menggunakan HTML, CSS, dan JavaScript murni tanpa ketergantungan *framework* berat agar performa pemuatan tetap cepat[cite: 1].
* **Desain Adaptif**: Tampilan responsif yang menyesuaikan ukuran layar ponsel maupun desktop.
